Poimi annetusta lääkärin kliinisestä potilaskertomuksesta keskeiset kliiniset entiteetit.
Palauta yksi JSON-objekti täsmälleen alla olevassa skeemassa. Älä lisää kenttiä. Älä lisää selityksiä.

TÄRKEÄÄ: Perusta poiminta tiukasti annettuun sisältöön. Älä keksi tietoja.
Jos jokin kategoria ei esiinny, palauta tyhjä taulukko kyseiselle kategorialle.

Skeema:
{
  "language": "string, e.g., fi or en",
  "entities": {
    "sairaudet": [],        // mainitut sairaudet/tilat (string)
    "oireet": [],          // oireet (string)
    "suunnitellut testit": [],     // tilatut tai suunnitellut testit (string)
    "tutkimustulokset": [],      // konkreettiset tulokset/havainnot (string)
    "diagnoosit": [],         // lääkärin diagnoosit (string)
    "lääkkeet": [],       // lääkkeiden nimet + annos jos mainittu (string)
    "allergiat": [],         // allergiat (string)
    "interventiot": [],        // toimenpiteet/interventiot (string)
    "hoitosuunnitelma": [],    // suunnitellut toimenpiteet (string)
    "muut avainsanat": []     // muut keskeiset kliiniset avainsanat (string)
  }
}
